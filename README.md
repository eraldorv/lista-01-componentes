# Exercício 1 - Cartão de Visita Digital ⭐ Fácil
## Crie um app que mostre seu cartão de visita profissional.
### Requisitos:<br>
Seu nome em destaque (fonte grande, negrito)<br>
Sua área de atuação (ex: "Desenvolvedor Mobile")<br>
Seu e-mail<br>
Seu telefone (ou placeholder)<br>
Fundo com cor personalizada<br>
Dica: Use View para container, Text para textos e StyleSheet para estilizar.<br>

# Exercício 2 - Perfil de Rede Social ⭐⭐ Médio
## Crie uma tela de perfil estilo Instagram/Twitter.

### Requisitos:<br>
Foto de perfil (use imagem da internet)<br>
Nome do usuário<br>
@username<br>
Bio (2-3 linhas de descrição)<br>
Estatísticas: Posts | Seguidores | Seguindo<br>

# Exercício 3 - Tela de App de Delivery ⭐⭐⭐
## Desafio
 Recrie a tela inicial de um app de delivery (estilo iFood/Rappi).<br>
### Requisitos:<br>
Logo ou nome do app no topo<br>
Barra de busca (só visual, não precisa funcionar)<br>
3 categorias com ícones/emojis: 🍕 Pizza | 🍔 Hambúrguer | 🍣 Sushi<br>
Banner promocional (imagem + texto "50% OFF")<br>
Estilização caprichada<br>
